# Motion library workflow

Blue Editorial is the default. All ten cards use layered scene direction in ../references/layered-scenes.md. For work in this output tree, use custom-motion-shorts-v2/SKILL.md for Classic or a named reference style. Start at ../references/style-library/index.html to find a source by style, type, or subject. The JSON and CSV indexes under ../references/style-library/catalog retain the source paths and content hashes.

NewSkillReference is the read-only source. Run the organizer in tools/ only to rebuild the working library from the audited inventory. An unexplained source hash change requires review. Keep blank prompts out of the working library. Retain all source aliases for files with identical content.
