Each numbered folder has both a per-image and a per-motion Markdown file. There are no separate README, config or notes files in the loose tree. The copied archive contains SKILL.md and four references: sfx-guide.md, stage-formats.md, style-builder.md and tool-profiles.md. These cover intake/staging, material-specific sound cues, the six-second poster template, configurable design locks and tool-specific prompt formats. Its example presets are written suggestions. Only styles with supplied visual evidence enter the observed library.

Style-4 has no poster for the paired shops, hourglass, isolated product or spotlight scene. Style-7 lacks the dartboard, mismatched plug, button and prism posters. Missing visual or motion evidence is marked explicitly. A single-shot source clip can show an exit treatment, but cannot establish what an editor cut to next.
