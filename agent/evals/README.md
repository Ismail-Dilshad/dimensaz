# Evals

Ten golden tasks covering the three modes, English, Sorani, Arabic and Persian,
voice timing, brand application and font choice. Inputs that need media
(`voiceover.wav`, `reference.mp4`, `interview.mp4`...) are not committed; supply
your own short clips you have rights to.

Run a task by giving the agent its `input` as a user request, then score it with
`rubric.md`. `tests/agent-structure.test.ts` checks that the task file stays valid.
