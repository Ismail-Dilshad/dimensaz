# Production memory

Before a new brief, search this file for the language, motion mechanism, source
format or tool needed. For example, run `rg -in 'Sorani|cutaway|FFmpeg' memory`.
Read only the matching entries and follow their linked evidence.

After each task, review what was verified. Update the existing entry with the
same ID or add one entry when the lesson is distinct. Keep the date, conditions,
evidence and practical consequence. Merge overlapping entries. Record explicit
preferences as preferences. Keep raw footage, transcripts, secrets, and
unverified claims in their proper project context.

- **sorani-shaping** · Complete shaped words in one of the existing Kurdish fonts, chosen by style, are the default for Sorani. Inspect joined text and mixed-direction lines in the actual render. [Language guide](../references/language-support.md)
- **presenter-cutaway** · Use a full-screen visual when a spoken beat benefits from a concrete demonstration. Keep dialogue continuous where the edit permits and return to the presenter for the close. [Editing guide](../references/short-form-editing.md)
- **local-render-check** · Windows baseline verified Node, FFmpeg, FFprobe and Chromium with `pnpm video:doctor` and two decoded smoke exports. On another host, run the same doctor before rendering. [Setup](../README.md#setup)
- **ismail-pendulum-revision** · For an explicitly requested revision of the approved style, preserve the cord wipe, smooth pivot and single CTA exit. [Approved recipe](../references/pendulum-reveal.md)
- **independent-product-tag** · On 2026-11-06, a silent 540×960 Sorani proof used a static shoe and an independently pivoted tag. The preview and encoded samples showed the tag settle by 0.98 seconds and the caption remain readable during the hold. [Layered scene guide](../references/layered-scenes.md)
