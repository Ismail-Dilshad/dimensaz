# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome people of every language and background, assume good
intent, and give constructive feedback. Harassment, insults and personal attacks are
not accepted in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behavior privately to the maintainer through GitHub
([@Eso70](https://github.com/Eso70)). Reports are handled confidentially. Maintainers
may remove comments, commits or contributions that break this code, and may ban
contributors temporarily or permanently.
