# Neutral Shopping Bag with Handles and Tag

Neutral generated PNG, not a mesh. Paper bag body, two handles and hanging tag. Accent mask separates handles and tag from the paper body; silhouette includes the openings between handles. Approximate masks require inspection at intended scale.

Use the accompanying silhouette and accent SVG masks in a compositor; do not modify the master. See color-recipe.json. The preview page demonstrates palette changes without regenerating the object. These helper masks are not imported scene assets or new renderer fields.
