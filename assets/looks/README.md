# Looks

Looks learned from videos you like (`pnpm dimensaz look learn URL --name NAME`). Each file holds
only measurements (brightness, colour temperature, cut rhythm, motion energy and easing) and the
style nudges and music mood they suggest; no frames, colours or footage of the source are kept.
Make a video in a look's spirit with `pnpm dimensaz make script.txt --like NAME`. See
docs/guides/looks.md.
