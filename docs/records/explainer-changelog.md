# Script-led explainer changes

Completed November 2, 2026. The original shop video provided the pacing and spacing reference.

- **Design selection.** The production checklist now asks for a script analysis. The theme picker uses its domain and recent choices to select a palette, background, icon family, rendering treatment and phrase highlight. Explicit colors and supported style overrides take priority. Each project saves its choices and rationale.
- **Meaning and hierarchy.** Six role templates and original vector symbols give each scene a focal point. Supporting symbols carry a stated meaning and enter in sequence. The duplicate checker records used icons and phrases and flags unexplained reuse. An overlap warning on supplied wording goes to editorial review.
- **Text and motion.** Complete Sorani phrases reveal at their first word cue. Fixed safe zones reserve room for later lines. The preview review caught a highlight extending into paragraph whitespace and two dense scenes that needed more entrance clearance. The corrected layout preserves all source separators and keeps them outside the painted highlight.
- **Audio.** A previously authorized CTC analysis can be bound to the source recording. Optional effects have a lower gain and the existing mixer ducks accompaniment under speech. The shop demo uses the supplied narration alone.
- **Review.** Each preview includes an HTML storyboard, scene stills, a reuse ledger and measured layout checks. The final review helper extracts half-second encoded frames. Five editorial criteria and the export hash tie the review to the delivered file. SRT captions and a short silent preview accompany each video.
- **Verification.** Both vertical production examples were rendered at 1080×1920 and 60fps. Layout tests also exercised square and landscape. The browser-enabled suite passed 171 tests and skipped one optional Python bridge test. The three edited skills passed metadata validation.
