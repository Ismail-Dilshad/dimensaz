# Asset rights

The eight procedural illustrations in asset-manifest.json are original CC0-1.0.
Every bundled font is under the SIL Open Font License (assets/fonts/open/licenses/).
Assets without a recorded license are not kept in the repository.
User uploads remain user-provided assets; do not assume external reuse rights.
Any new asset must record source, license, tags, path, width and height.
No downloader or external asset search runs automatically.
