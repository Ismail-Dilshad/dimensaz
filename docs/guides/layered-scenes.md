# Directing a layered scene

**Blue Editorial is the default.** Use a different card when the user names it, or run the picker in Auto mode when they ask you to choose. Set the resolved name in the creation request's `styleCard` field. All active cards use the same independent-layer stage in the main project. Saved projects retain their recorded look.

Start with a verb in the script. For “attract,” identify what attracts and what is drawn in. For “arrive,” identify the traveler and the destination. For “send,” identify the carrier, message and recipient or departure point. Pick one specific poster in the selected folder and record its catalog-relative project path in the scene's evidence. Inspect a relevant clip for how the elements hand off. Record which choices come from a still and which were seen in motion.

Plan **two to four meaningful, independently placed objects** for an ordinary scene. A complex mechanism may need more individual parts. A single flattened group cannot show a hand releasing a message, a drawer opening, or a dart arriving. Reserve one clear focal point. Place the companion where it physically acts on the hero. Insert a signal, halo, path or small inset only when it explains direction, state or result.

**Storyboard each role.** Specify the exact hero ID, each companion ID, source anchor, final bounds, depth and contact point. Note intentional overlaps by naming the two objects, e.g. the dart tip in the bullseye. Keep headlines unobstructed. Match horizon, scale, perspective, light direction and edge quality across the set. Avoid a generic row of small icons below a large one.

**Set a motion score.** Establish the stage, move the part that explains the verb, let its receiver respond and hold the resolved scene. A parked layer stays still. Use a 0.4–0.6 s beat for a simple settle, or a track with distinct entry, hold and exit poses for one object. Put its pivot on the attachment for rotation. The card stage eases velocity and acceleration to zero at both ends. Preview the start, quarter, middle, three-quarter and end of each move, plus transitions. Check the aligned phrase against actual voice cues.

**Source the set.** Search local reviewed assets first. When a part is missing, use legitimately reusable official downloads or generate an isolated subject. Acquire the needed companions as well as the hero. Verify rights, cutout edges and style compatibility, register the actual files, and pin all layers before review. A broad download permission is sufficient for routine permitted sourcing. Log unresolved rights or account/payment requirements.
