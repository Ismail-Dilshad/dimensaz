# Every scene gets a packet

Use this sequence for Blue Editorial (default), any other selected card, or a documented remix. Name the card, the specific source still/clip and why its staging fits the script. A remix names its base and the borrowed choices. Choose one idea per continuous source slice. Keep supplied words and separators exact. New authored copy and visual metaphors should advance the idea. Explain a deliberate callback or an author-supplied repeated phrase.

Use the following seven headings under **Scene N — Title**. Complete the inventory before calling any generation tool. Only section 3 can supply an image-generation request. Neither master prompt nor the assembly spec goes to an image or video model. Never request an asset sheet, several objects in one image, a combined mechanism to slice later, or a poster.

1. **Master image prompt.** Describe the resolved still in one paragraph. Specify layout, mood, palette, materials, lighting direction, focal point, supporting objects, contact and reading order. Use the chosen source as visual evidence. This is the comparison target for the composited still.
2. **Layer table.** Use `Layer | Type | Already available? | Generate?`. Give every independently placeable item a stable ID. Use background, color, shape, asset or text. Register colors, grid, dots, gradients, guides, shadows, highlight chips and real type as named compositor elements. Search the project asset library for each object, including synonyms and already-created parts. Record library ID, file/hash, instance and prior use. Existing items always resolve to reuse. A new missing object is reserved once in the registry before generation. Multiple instances share the same bytes and have different transforms.
3. **Asset prompts.** One request for **one** missing object or independently moving part. State subject, fixed pixel dimensions, registration, pose/viewpoint, palette/material, light vector and attachment. Center the whole silhouette with padding on transparent or readily removable plain color. Exclude lettering, scenery, other parts and shadows cast onto the background. A phone body and its screen content are distinct layers. Wheels that rotate have their own axle pivot, and sound waves travel separately from the horn. Static integral details may remain on the object. Register and pin the approved result, replacing its pending reservation. If everything exists, write “None — all layers resolved.”
4. **Assembly prompt.** Specify 1080×1920, safe margins in pixels, text and art zones. Give each instance a box, placement anchor, local pivot, scale, rotation and back-to-front z-order. Record deliberate contact/occlusion and where clear space is required. Assemble in code from the actual layers. Inspect the still against section 1 for hierarchy, lighting, complete silhouettes and RTL readability. Save the still and the observed differences. Fix failures before marking the scene reviewed.
5. **Master motion prompt.** Choose the scene duration at 60 fps. For a silent scene, weigh the words the viewer must read, the number of actions they must follow, and the hold the idea needs. A brief question can cut quickly. A comparison needs time to see both objects and the result. For narration, use the recording’s bound cues and natural pauses. Let the available speech window guide the choreography. Identify the first point of attention and what changes because of the action. Name entry, settled reading hold and exit or cut. Static is the starting assumption. Use a single easing family for the style. A static subject can still have its own layer and pivot.
6. **Motion table.** Use `Layer | Moves? | Motion (what, how far, direction) | Start–end | Easing | Pivot`. Include **only moving layers**. Each motion cell is the individual layer's motion prompt. Specify initial and final transforms, units and reason. A normal transition occupies 24–36 frames. Stagger subtle supporting actions, allow one dominant motion at a time, and keep outgoing and incoming elements temporally separate. Reveal complete shaped phrases as one unit and preserve Kurdish joining. No ghost copies, trails, jitter or ambient motion across the whole set.
7. **Final motion assembly timeline.** Merge events on one frame clock. Frame ranges are half-open; a scene with N frames displays frames 0 through N−1 and cuts at N. Start the next scene at the cumulative frame count. Include exact layer entries, holds, exits, first state, last visible state and the next opening. If the ending and next opening share a position or silhouette, name it and compare the two frames. Otherwise specify a clean cut. Static layers hold throughout unless explicitly cut. Report global scene ranges separately.

Before advancing, check source coverage, repeated phrases/subjects and documented callbacks; registry reuse; separate controls and pivots; safe placement and deliberate overlap; still-versus-master inspection; and agreement with the chosen scene duration. Return a final table of every scene, its assets, local action times and global range. For narration, compare cuts and phrase reveals to the recording's bound cues. Revise the motion and reading hold to fit the actual cuts. Never stretch the voice or infer new cues to fit the board.

## Use the packet helper

The agent maintains one UTF-8 JSON sidecar per project. Set the packet version to 2 and give every scene its chosen scoreFrames. Version 1 packets retain their historical six-second interpretation when they omit the field. Start with the `packetDraft` returned by the host's `video:reference plan`. Fill it in and keep it outside the strict render manifest. Run `python scripts/scene_packet.py PLAN.json --root PROJECT_ROOT --out NEW_DIRECTORY` from this skill. The helper writes a reviewable Markdown packet with the summary table, a registry and an isolated-asset queue. A draft can contain missing assets. Include a still and inspection note after comparing each assembled frame against the master. The draft registry returns a `reviewKey` per scene. After inspection, save that key as `scene.reviewKey` and run again with `--reviewed`. This binds the review to its current still, style anchor, plan and assets. Repeat in a fresh output directory after any change.

- Project fields: `title, script, style, rationale, look, assetLook, easing, timingNote, registry, baseLayers, scenes`. The scene-wide `look` may describe a grid or typography. Keep `assetLook` limited to the object's palette, surface, perspective and lighting. The registry maps stable object keys to a verified host `assetId` or to `{subject, size, pose, registration}` for an isolated new object. Update the same entry with its library ID once sourced. Check style, rights and subject visually before assigning an ID.
- Each scene has `title, copy, scoreFrames, anchor, image, motion, safe, art, text, contact, layers, moves, first, last, cut`. The three zones and all boxes use pixels as [left, top, width, height]. A layer has `id, type, source, box, anchor, pivot, scale, rotation, z`; points are local fractions. Supply a distinct instance ID for each independently addressable part. Source names for native layers identify the code component or style token. Attach a `callback` to repeated objects and a `copyCallback` to repeated phrasing.
- Moves have `layer, start, end, prompt`, optional `dominant` (default true) and `phase` (enter, action or exit). Times are integer scene-local frame boundaries. Native layers can move, including phrase or attached chip. For a clean cut, keep poses parked through the last visible frame and remove outgoing layers at the cut. Each scene may have a `still` (relative to the plan), `stillHash` (SHA-256) and `inspection`. Use a fresh still after any plan or asset revision. Run host pilot, geometry, fingerprint and encoded-frame checks for a video.

For a host video, add `--project PATH/TO/project.json` at final review. It checks the locked asset IDs, object stacking, boxes, pivots, rotation, action windows, source, style, evidence and per-scene frame counts against the saved render manifest. For an approved remix use `baseCard` to name its registered host card. Inspect actual motion direction, optical balance and phrase appearance in the preview.
