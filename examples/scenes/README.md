# Created collection

Finished Kurdish example scenes made with the reference styles: each folder has the
final `recreation.png`, a side-by-side `comparison.png` with its reference, the numbered
`layers/` and a self-contained `*-editable.svg` (images and font embedded).

The 3D objects these scenes use live in `../library/objects-3d`; `inventory.json` maps
them. Superseded first versions, per-scene asset copies and 2D cut-out sources were
removed in 3.2.0.
